# Plumbline web identity assets

These assets are the source-owned Plumbline web identity used by the
`plumblines.uk` client. The emblem is imported from the companion
`edriffles-blog/src/assets/edriffles-emblem.png` file without transformation.

- Emblem SHA-256: `ee3878bd56728173e40e36cb5fa8e1f2ab061d69fcf63df35f51277b8d486c46`
- Browser favicons are copied from the companion blog's `public/` set.
- Native upstream app-icon variants remain separate and are not used by the
  web-only identity layer.
